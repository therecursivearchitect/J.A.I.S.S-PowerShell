# J.A.I.S.S. PowerShell Subsystem Integration

## Overview
This module bridges local PowerShell automation with hardware virtualization management (`SAIHV`), enabling seamless subsystem control, directory tracking, and script execution across local lab environments.

## Core Integration Features
* **Subsystem Control:** Native PowerShell automation bindings for real-time environment diagnostics and secure script execution.
* **Persistent Pathing:** Automated directory routing and validation ensuring reliable return paths to the primary root architecture (`C:\Users\timpa\OneDrive\Documents\SAIHV`).
* **Session Lifecycle Management:** Automated directory tracking and clean shutdown routines across operational instances.
